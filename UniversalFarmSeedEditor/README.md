# 种子档案室

这是随 UniversalFarm 仓库分发、独立运行的离线数据编辑器，位于仓库内的 `UniversalFarmSeedEditor/`。整个目录仍可以单独复制到其他电脑，无需安装 Node、Python 或 three.js。

## 启动

直接双击 `index.html`，或双击 `start.bat`。页面只加载同目录下的普通脚本，不需要本地服务器。

浏览器草稿不会随 Git 或目录搬迁自动迁移；有未导出的修改时，请从原地址导出数据，再在新地址导入。

## 编辑

- 左侧选择作物，也可搜索、新增、复制、删除。
- 身份与价格、生长阶段、周期、连收、浇水间隔、缺水容忍、土地、气候、获取方式、野外生成、用途、加工配方与模型颜色均可编辑。
- 阶段天数的合计必须等于成熟天数，阶段天数数量等于图标数量减一。
- 本机草稿仅在数据合法时自动保存。浏览器可能禁用本地文件存储，因此请使用导出文件备份。
- 校验失败会禁止导出，不会把 JavaScript 文本当作代码执行。

## 与游戏交换数据

1. 导出 `crop-catalog.json`，在游戏的“农场”页签选择“导入独立编辑器数据”。游戏会验证数据、保存进度并刷新。该覆盖数据仅对当前浏览器和游戏地址生效。
2. 或导出 `crops.js`，替换游戏工程的 `src/data/crops.js`，更新项目默认图鉴。种子、收获物、品质变体和模型自动从此数据派生。
3. 导入游戏原来的 `crops.js` 或编辑器导出的 JSON 可继续修改。导入不依赖游戏目录。

不要删除/改名正在使用的种子、作物和收获物 ID。游戏会阻止删除当前背包或农田使用的条目；更新项目默认数据时也应保留旧 ID。

气候、野外生成和加工配方属于预留数据，这一版不生成野外种子、不提供加工设备。`availability.sources` 是获取说明标签，不会改变游戏初始背包。当前游戏支持的科技 ID 可从游戏 `src/data/techs.js` 查询。

`catalog.js` 是独立的规则和内置图鉴快照。如游戏内置图鉴或校验规则有变化，可在游戏工程运行 `npm run editor:sync` 重新生成此快照；编辑器运行时仍不依赖工程。

# 开发路线图

状态：✅ 完成 · 🚧 骨架已有 · ⬜ 未开始

## M0 架构骨架（当前）
- ✅ 核心：Game / EventBus / Registry / 存档 / 可复现随机数
- ✅ 数据：物品、作物、星球特质、群系、宇宙层级、科技、矿脉
- ✅ 种田循环：开垦 → 播种 → 浇水 → 过夜生长 → 收获
- ✅ 经济：买种子、卖产物
- ✅ 科技：研究消耗资源 → 解锁功能
- 🚧 挖矿：每日矿点 + 敲击（待做：矿洞分层、地图）
- 🚧 宇宙：程序化星系/星球 + 特质修正
- 🚧 航行：星球间跳转（待做：燃料、航行时间、星图可视化）
- ✅ 逻辑层单元测试 `npm test`

## M1 起源星球打磨
- ⬜ 玩家角色在地图上移动（Canvas 视图），替代点格子
- ⬜ 季节 / 天气，影响作物
- ⬜ 作物品质、肥料、洒水器（自动化萌芽）
- ⬜ 飞船作为基地：可升级的仓库、工作台

## M2 挖矿深化
- ⬜ 矿洞多层，越深越稀有，有危险
- ⬜ 精炼 / 合成配方系统（recipes.js + CraftingSystem）

## M3 科技与出航
- ⬜ 研究需要时间，而不是瞬间完成
- ⬜ 星图可视化（星系节点 + 航线）
- ⬜ 不同星球的专属作物 / 矿物 / 遗迹

## M4 殖民经营（群星味）
- ⬜ 多星球基地，离线产出
- ⬜ 自动化：无人机、物流航线

## M5 深空与升维
- ⬜ 随机事件 / 异常 / 外星生物
- ⬜ 高维空间：改变规则的新维度（时间倒流的农田、四维矿脉…）
